PLACE YOUR BACKGROUND MUSIC HERE
================================

Add your audio file to this folder and name it exactly:

    i-see-the-light.mp3

That's it. The site will automatically:
  - start the song softly when a guest clicks "Open Invitation"
  - gently fade the volume in over ~4 seconds
  - show a mute / unmute control (the guest's choice is remembered)

Notes:
  - .mp3 is recommended for the widest browser support.
  - If you want a different filename or format, update AUDIO_SRC in
    src/components/experience/music-player.tsx
  - If no file is present, the music control is simply hidden and the
    rest of the experience works perfectly.

Reminder: please make sure you have the rights to use any music you add.
